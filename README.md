# Второй мозг для ИИ

Папка, благодаря которой ИИ помнит вас, ваши проекты и решения - и сам поддерживает эту память.
Работает в Claude Code (Anthropic) и Codex (OpenAI). Из ролика «Как заставить ИИ помнить вас и ваши проекты».

## Быстрый старт

**Вариант 1. Архив (надёжнее всего).**
1. Скачайте архив (в боте или здесь: зелёная кнопка **Code** → **Download ZIP**).
2. Распакуйте его - получится папка (её можно переименовать и перенести куда удобно).
3. Откройте эту папку в Claude Code или Codex и напишите:

```
Настрой мой второй мозг
```

**Вариант 2. Одной фразой по ссылке.** Откройте пустую папку в Claude Code или Codex и отправьте:

```
Настрой мой второй мозг отсюда: https://github.com/nikitagrishunin/vtoroy-mozg. Если не можешь открыть ссылку, остановись и скажи мне.
```

ИИ скачает папку - несколько раз спросит разрешение выйти в интернет и скопировать файлы: каждый раз жмите
«Разрешить». Потом начнёт задавать вопросы, по одному. Отвечайте хоть голосом и объясняйте «почему» к каждому правилу.

После настройки - одна привычка: в конце каждой сессии говорите **«закругляемся»**.

## Что нужно

- Любой компьютер последних 7-8 лет (Mac или Windows). ИИ работает на серверах компании, компьютер только хранит папку.
- Claude Code (платный тариф Claude) или Codex (работает и на бесплатном аккаунте ChatGPT, но с жёсткими лимитами).
- Ни терминала, ни кода.

## Что внутри

| Файл | Зачем |
|---|---|
| AGENTS.md | Главный файл. Грузится каждую сессию: кто вы, правила, на которых держится память, где что лежит. Codex читает его сам. |
| CLAUDE.md | Одна строка, которая подгружает AGENTS.md в Claude Code, - поэтому одна папка работает в обоих. |
| SETUP.md | Пошаговая настройка для ИИ. После настройки уезжает в `archive/`. |
| sessions.md | Где вы остановились: Сделано, Решили, Дальше. |
| decisions.md | Что вы решили и почему. |
| memory/ | Один факт - один файл, с понятными именами. |
| projects/ | По папке на проект, в каждой короткий STATE.md. |
| skills/ | Как вы делаете повторяющиеся задачи. |
| inbox/, archive/ | Разобрать. Закрытое. |
| .claude/, .agents/ | Безопасные разрешения для Claude Code и скилл настройки для Claude Code и Codex. |
| PROMPTS.md | Все промпты из ролика. |

## Почему устроено так

- ИИ начинает каждую сессию с чистого листа и знает только то, что ему подгрузили. Поэтому главный файл грузится сам.
- Чем больше загружено, тем расплывчатее внимание, а середина длинного текста теряется. Поэтому главный файл -
  оглавление, а подробности лежат в отдельных файлах.
- ИИ находит файлы поиском по именам и словам. Поэтому один факт - один файл с понятным именем.
- Память, которую ИИ пишет сам себе, может испортить результат. Поэтому он предлагает, а вы говорите «да».

## Разрешения

- Когда Claude впервые открывает папку, он спрашивает, доверяете ли вы ей. Папка ваша - «да».
- Claude Code: папка включает режим «Accept edits» (`.claude/settings.json`): ИИ правит файлы в этой папке без вопросов,
  но спрашивает перед большинством команд и перед выходом в интернет.
- Codex: если спросит, доверяете ли папке, - «да». Режим «Ask for approval» по умолчанию оставьте: правки в папке,
  а перед интернетом спросит. Чтобы он скачал набор по ссылке, разрешите, когда спросит.
- «Bypass permissions» (Claude Code) и «Full access» (Codex) дают ИИ делать всё без спроса. Не в первый день.

## Безопасность

- Никогда не кладите в эту папку пароли, номера карт и паспортные данные.
- В главном файле есть правило: ничего не отправлять, не оплачивать, не удалять и не публиковать без вашего согласия.
  Оставьте его.
- Это ваша папка. Делайте её резервную копию, как любой другой папки.
