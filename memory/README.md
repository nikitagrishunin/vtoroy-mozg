# Память

Один факт - один файл. Короткие понятные имена, чтобы ИИ находил их поиском: `подписки.md`, `здоровье.md`,
`расписание-детей.md`. Файл `заметки-финал-3.md` не найдётся никогда.

В каждом файле: сам факт, дата, когда он был верен, и почему он важен.
